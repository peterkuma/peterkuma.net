## Software

### Scientific software

<h4><a href="https://github.com/peterkuma/ccplot">ccplot</a></h4><p>Command-line tool for visualizing data from CloudSat and CALIPSO satellites (<a href="https://ccplot.org">ccplot.org</a>)</p>
<h4><a href="https://github.com/peterkuma/cl2nc">cl2nc</a></h4><p>Command-line tool for converting ceilometer data files to NetCDF, supporting Vaisala CL51, CL31, and CT25K (<a href="https://pypi.org/project/cl2nc/">https://pypi.org/project/cl2nc/</a>)</p>
<h4><a href="https://github.com/peterkuma/mrr2c">mrr2c</a></h4><p>Command-line tool for converting Metek MRR-2 micro rain radar data to NetCDF (<a href="https://pypi.org/project/mrr2c/">https://pypi.org/project/mrr2c/</a>)</p>
<h4><a href="https://github.com/peterkuma/mpl2nc">mpl2nc</a></h4><p>Command-line tool for converting Sigma Space Micro Pulse Lidar (MPL) data to NetCDF (<a href="https://pypi.org/project/mpl2nc/">https://pypi.org/project/mpl2nc/</a>)</p>
<h4><a href="https://github.com/peterkuma/ccbrowse">ccbrowse</a></h4><p>Web application for browsing data from the CALIPSO and CloudSat satellites (<a href="https://ccplot.org/ccbrowse">ccplot.org/ccbrowse</a>)</p>
<h4><a href="https://github.com/alcf-lidar/alcf">ALCF</a></h4><p>Automatic Lidar and Ceilometer Processing Framework (ALCF) – atmospheric lidar simulator and data processing command-line tool and Python package (<a href="https://alcf.peterkuma.net">alcf.peterkuma.net</a>)</p>
<h4><a href="https://github.com/peterkuma/rstool">rstool</a></h4><p>Command-line tool for converting radiosonde measurement data to NetCDF and calculation of derived physical quantities, supporting InterMet Systems (iMet) and Windsond radiosondes, as well as calculating derived quantities from model profiles (<a href="https://pypi.org/project/rstool/">https://pypi.org/project/rstool/</a>)</p>
<h4><a href="https://github.com/peterkuma/ds-format">ds format</a></h4><p>Command-line tool and a Python package for reading and writing scientific data (<a href="https://ds-format.peterkuma.net">ds-format.peterkuma.net</a>)</p>
<h4><a href="https://github.com/peterkuma/aquarius-time">Aquarius Time</a></h4><p>Scientific time library for Python (<a href="https://pypi.org/project/aquarius-time/">https://pypi.org/project/aquarius-time/</a>)</p>
<h4><a href="https://github.com/peterkuma/alcf-precip">ALCF-precip</a></h4><p>Artificial neural network for detecting precipitation in lidar data for use with the Automatic Lidar and Ceilometer Framework (ALCF), described in <a href="https://doi.org/10.1029/2024JD043145">Ship-based lidar evaluation of Southern Ocean low clouds in the storm-resolving general circulation model ICON and the ERA5 and MERRA-2 reanalyses</a> by Kuma et al. (2025)</p>
<h4><a href="https://github.com/alcf-lidar/alcf-cosp">ALCF-COSP</a></h4><p>Atmospheric lidar simulator implementation for the Automatic Lidar and Ceilometer Framework (ALCF) – a forked version of COSP (<a href="https://alcf.peterkuma.net">alcf.peterkuma.net</a>)</p>
<h4><a href="https://github.com/peterkuma/rtc">rtc</a></h4><p>R package for tree clustering based on Bayesian inference</p>
<h4><a href="https://github.com/peterkuma/libtc">libtc</a></h4><p>Tree clustering C library based on Bayesian inference</p>
<h4><a href="https://github.com/peterkuma/nc_dump">nc_dump</a></h4><p>Code for outputting data from the ALADIN numerical weather prediction model</p>
<h4><a href="https://github.com/peterkuma/dump2h5">dump2h5</a></h4><p>Command-line tool for converting data from nc_dump to NetCDF/HDF5</p>
<h4><a href="https://github.com/peterkuma/forces-ecs">FORCeS ECS</a></h4><p>Code for combining emergent constraints produced by the FORCeS project using the Bretherton and Caldwell (2020) method</p>
<h4><a href="https://github.com/peterkuma/bcc200-ocr">BCC200 OCR</a></h4><p>Command-line tool for reading timestamps from the BCC200 camera images</p>

#### Open-source software

<h4><a href="https://github.com/peterkuma/fileshackproject">Fileshack</a></h4><p>Web application for a self-hosted web file storage (<a href="https://fileshack.peterkuma.net">fileshack.peterkuma.net</a>)</p>
<h4><a href="https://github.com/peterkuma/django-attach">django-attach</a></h4><p>Django admin plugin for attaching files to model instances with multiple file selection support (<a href="https://pypi.org/project/django-attach/">https://pypi.org/project/django-attach/</a>)</p>
<h4><a href="https://github.com/peterkuma/wstcp">WSTCP</a></h4><p>node.js client and server implementation of TCP forwarding over WebSocket (<a href="https://www.npmjs.com/package/wstcp">www.npmjs.com/package/wstcp</a>)</p>
<h4><a href="https://github.com/peterkuma/wstcp-server">WSTCP Server</a></h4><p>Command-line server for persistent TCP port forwarding over WebSocket (<a href="https://www.npmjs.com/package/wstcp-server">www.npmjs.com/package/wstcp-server</a>)</p>
<h4><a href="https://github.com/peterkuma/wstcp-client">WSTCP Client</a></h4><p>Command-line client for persistent TCP port forwarding over WebSocket (<a href="https://www.npmjs.com/package/wstcp-client">www.npmjs.com/package/wstcp-client</a>)</p>
<h4><a href="https://github.com/peterkuma/picture-slider">PictureSlider</a></h4><p>JavaScript library for an animated picture slider (<a href="https://picture-slider.peterkuma.net">picture-slider.peterkuma.net</a>)</p>
<h4><a href="https://github.com/peterkuma/pst">PST</a></h4><p>Command-line tool and a Python package for parsing Plain Structured Text (PST) (<a href="https://pypi.org/project/pst-format/">https://pypi.org/project/pst-format/</a>)</p>
<h4><a href="https://github.com/peterkuma/django-linguo">Django Linguo</a></h4><p>Fork of django-linguo with support for more recent version of Django</p>
<h4><a href="https://github.com/peterkuma/bunyan-streams-config">Bunyan Streams Config</a></h4><p>node.js package for creating bunyan streams from JSON configuration (<a href="https://www.npmjs.com/package/bunyan-streams-config">www.npmjs.com/package/bunyan-streams-config</a>)</p>
